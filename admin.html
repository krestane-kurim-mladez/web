1. Připojení ke GitHubu

Jak získat token (jednorázově)
  1. Na GitHubu otevři Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Klikni na Generate new token, pojmenuj ho a nastav platnost (např. 1 rok).
  3. V Repository access vyber Only select repositories a zvol repozitář tohoto webu.
  4. V Permissions → Repository permissions nastav Contents: Read and write.
  5. Vygeneruj token, zkopíruj ho a vlož sem. Token nikomu neposílej.
