1. Připojení ke GitHubu

Návod: Jak nastavit GitHub token (jednorázově)
  1. Otevři GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Klikni na Generate new token, zadej název (např. Mladez Admin) a platnost.
  3. V Repository access vyber Only select repositories a označ repozitář webu.
  4. V Permissions → Repository permissions nastav Contents: Read and write.
  5. Vygeneruj token, vlož ho sem a klikni na Načíst data z GitHubu.
